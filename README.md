# CapsLock-Switch
使用 AutoHotkey 修改 Windows 中 CapsLock 键的功能，使其操作逻辑与 macOS 相同
## 说明
- CapsLockSwitch.ahk 需要使用 AutoHotkey v2.0 版本，CapsLockSwitch_v1.0.ahk 则需要使用 AutoHotkey v1.0 版本
- CapsLock 键的功能被修改为短按切换中英文，长按切换大小写
- 默认使用 Ctrl+Space 作为切换中英文的快捷键，如果使用其它快捷键请在代码中修改
- 长按时间阈值默认为 0.3s，如果不合适可以自行调整
- 该脚本在开头添加了自动以管理员权限运行，这是为了让脚本在一些系统级窗口中也能够使用
## 使用指南
1. 进入 AutoHotkey 官网 https://www.autohotkey.com/ 安装 AutoHotkey v2.0 版本
2. 下载 CapsLockSwitch.ahk 脚本，双击运行，在任务栏隐藏的图标中看到 CapsLockSwitch.ahk 即为运行成功
3. 如果想要实现开机自动运行，则可以添加一个任务计划程序，具体操作如下：
   - 在开始菜单搜索**任务计划程序**，然后在右边的操作中点击**创建任务**（注意：不是创建基本任务）
   - 首先输入名称，然后勾选**使用最高权限运行**
   - 在上方进入**触发器**选项，点击新建，开始任务选择**登录时**
   - 进入**操作**选项，点击新建，在**程序或脚本**中填入 AutoHotkeyUX.exe 的路径，在**添加参数**中填入 CapsLockSwitch.ahk 的路径
   - 进入**条件**选项，取消勾选**只有在计算机使用交流电源时才启动此任务**
   - 进入**设置**选项，取消勾选**如果任务运行超过一下时间，停止任务**
   - 最后点击确定即可创建完成，可以点击**运行**测试程序是否正常
